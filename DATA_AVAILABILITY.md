# Deposit locations

Code repository: https://github.com/luohafoluoqinghua/UC-BD-MDD-SCZ-computational-workflows

Code snapshot DOI: https://doi.org/10.5281/zenodo.23527110 (Zenodo record 23527110).

This release contains the 31 scripts enumerated in script_name_mapping.csv and supporting software-version, parameter and provenance documentation. The four processed GWAS tables and three Seurat objects described in data_manifest.csv are not included in this GitHub repository or the Zenodo code snapshot. The manifest records inspected local input files, not publicly deposited data files.

Original data sources are IEU OpenGWAS (UC: ebi-a-GCST004133; BD: ieu-b-5110; MDD: ieu-b-102; SCZ: ieu-b-5102) and GEO (GSE182270, GSE214695 and GSE254569). Consult the original studies for access conditions. Public source accessions do not replace the missing processed inputs or harmonized intermediate outputs. Consult REPRODUCIBILITY_STATUS.md before making claims about complete numerical reproducibility.
